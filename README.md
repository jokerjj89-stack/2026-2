# 부스 QR 방문 카운터

부스마다 전용 QR을 만들고, 방문객이 휴대폰으로 QR을 찍으면 그 부스 방문자 수가 실시간으로 올라가는 사이트입니다.
Node.js(18 이상)에서 실행됩니다. 처음 한 번 `npm install`이 필요합니다.

## 실행

```bash
npm install
ADMIN_PASSWORD=원하는비밀번호 node server.js
```

브라우저에서 `http://localhost:3000/admin`에 접속한 뒤 비밀번호로 로그인합니다.

## 사용 순서

1. **부스 추가**: 관리자 화면에서 부스 이름 입력 (줄바꿈으로 여러 개 한 번에)
2. **QR 인쇄**: "QR 전체 인쇄" → A4로 인쇄해서 각 부스에 부착
3. **방문객**: 휴대폰 카메라로 QR 찍기 → "방문이 기록되었어요" 화면 + 몇 개 부스를 돌았는지 표시
4. **현황 확인**: 관리자 화면이 3초마다 자동 갱신. CSV로 내려받아 엑셀에서 열 수 있음

## 집계 방식

- **방문자**: 같은 휴대폰이 같은 부스를 여러 번 찍어도 1명 (브라우저 쿠키로 구분)
- **스캔**: 찍은 전체 횟수 (10초 안의 중복 새로고침은 제외)

## 인터넷에 올리기 (Render 무료 요금제)

1. Render에서 **New → Blueprint** → 이 저장소 선택
2. `ADMIN_PASSWORD` 입력 → **Deploy Blueprint**
3. 웹 서비스와 무료 Postgres 데이터베이스가 함께 만들어집니다.

- 무료 데이터베이스는 **만든 날로부터 30일 뒤 만료**됩니다. 행사가 끝나면 CSV를 꼭 내려받으세요.
- 무료 서버는 15분간 접속이 없으면 잠듭니다. 깨어 있는 동안에는 서버가 10분마다 스스로를 불러 잠들지 않게 합니다.
  행사 시작 전에 관리자 화면을 한 번 열어 서버를 깨워 두세요.

⚠ QR 안에는 사이트 주소가 들어갑니다. **배포된 주소로 접속한 상태에서 QR을 인쇄**하세요.

## 환경변수

| 이름 | 설명 | 기본값 |
|---|---|---|
| `ADMIN_PASSWORD` | 관리자 비밀번호 | `admin1234` (꼭 바꾸세요) |
| `DATABASE_URL` | Postgres 주소 (Render가 자동 설정) | 없으면 파일에 저장 |
| `PORT` | 포트 | `3000` |
| `DATA_FILE` | DB가 없을 때 저장 파일 | `./data/data.json` |
| `PUBLIC_URL` | QR에 넣을 사이트 주소 | 접속한 주소 자동 사용 |
| `KEEP_ALIVE` | `0`이면 잠들기 방지 끄기 | 켜짐 |
